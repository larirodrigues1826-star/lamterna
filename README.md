# 💡 Simulação de Interruptor de Lâmpada

## 📌 Sobre o projeto

Este projeto consiste em uma página web interativa que simula o funcionamento de um interruptor de lâmpada.

Ao clicar no botão, o usuário consegue ligar e desligar a luz, alterando o ícone da lâmpada, as mensagens exibidas e as cores de fundo da página.

O projeto foi desenvolvido com HTML, CSS e JavaScript, com o objetivo de praticar conceitos básicos de desenvolvimento web e manipulação dinâmica de elementos HTML.

## 🚀 Funcionalidades

- **Ligar a lâmpada:** altera o ícone para representar a luz acesa.
- **Desligar a lâmpada:** retorna ao estado inicial.
- **Alteração de cores:** modifica o fundo e a cor do texto conforme o estado da lâmpada.
- **Mensagens dinâmicas:** informa ao usuário se a luz está ligada ou desligada.
- **Botão interativo:** altera seu próprio texto entre "Ligar" e "Desligar".

## 🛠️ Tecnologias utilizadas

- **HTML5:** estrutura da página.
- **CSS3:** estilização e efeitos visuais.
- **JavaScript:** lógica de funcionamento e interatividade.
